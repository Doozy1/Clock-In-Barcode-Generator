Clock-In Barcode Maker

Create barcodes for your SSO user ID, SSO Password, and the answer to your security question.

Security Warning: It is never a good idea to type in any username or password into a website you do not trust. A website could save anything you type into it. Even this page could, but it doesn't. The full source code for this page is publicly available on GitHub so anyone can verify exactly what it does to ensure transparency and honesty.
Private & Local: Everything you enter is processed directly on this device. Your SSO user ID, Password, and the answer to your security question are not sent anywhere or stored by this page in any way. All barcode images are created directly by your device using instructions provided by this page. Everything is self-contained.

1. Username (SSO ID)

The barcode caption will automatically say Username.

2. SSO Password

The barcode caption will automatically say Password. Your actual SSO password will not be shown below the barcode.

3. Security Question Answer

Enter the answer to your SSO security question as you would normally type it. The barcode caption will say Security Question Answer.
